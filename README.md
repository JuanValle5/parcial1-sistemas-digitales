# Parcial 1 / Práctica: Circuitos Combinacionales — Sistemas Digitales

Desarrollo teórico, reducción booleana, mapas de Karnaugh, diagramas lógicos, código VHDL para simulación en **Quartus II** y guía de montaje en protoboard para la práctica de **Circuitos Combinacionales** (Universidad del Valle).

## Contenido del Repositorio

* 📄 [Practica circuitos combinacionales.pdf](Practica%20circuitos%20combinacionales.pdf) — Guía original del laboratorio / parcial.
* 🧩 [punto_1.md](punto_1.md) — Análisis, seguimiento de pines, reducción algebraica ($Y = A$) y tabla de verdad del circuito con CI `7400`.
* 🚦 [punto_2.md](punto_2.md) — Diseño y reducción del circuito de encendido de dos LEDs (rojo y verde) mediante tres pulsadores ($a, b, c$).
* 🚨 [punto_3.md](punto_3.md) — Sistema de alarma de cuatro detectores ($a, b, c, d$) con condiciones de indiferencia (*Don't Care*) reducido a $F = d + ab$.
* 🏭 [punto_4.md](punto_4.md) — Control digital de tres tanques (reemplazo de PLC con 5 sensores $S_1, S_2, S_3, N_2, N_3$ y 6 salidas $A_1..A_3, B_1..B_3$) e implementación con matriz de diodos `1N4148`.
* 🔀 [punto_5.md](punto_5.md) — Construcción de una compuerta OR exclusiva (XOR) desde su tabla de verdad y comparación con el CI `74LS86`.
* ⚖️ [punto_6.md](punto_6.md) — Verificador de paridad par para una palabra de 8 bits mediante árbol balanceado de compuertas XOR (`74LS86`).
* 🛡️ [punto_7.md](punto_7.md) — Código Hamming $(7,4)$ de detección y corrección automática de errores para palabras de 4 bits.
* 🛒 [lista_materiales.md](lista_materiales.md) — Lista completa y detallada de materiales para el montaje real en protoboard.
